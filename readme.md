Student Grade Management System
A web application built with Django to manage student grades at a university.
Description
This system allows administrators, teachers, and/or students to manage and view academic grades in an organized and efficient way.
Features (planned)
	•	Student management (add, edit, delete)
	•	Course/subject management
	•	Enter and edit grades
	•	Average calculation and report card generation
	•	User authentication (admin, teacher, student)
Technology
	•	Language: Python
	•	Framework: Django
	•	Database: SQLite (development) / PostgreSQL (production)
